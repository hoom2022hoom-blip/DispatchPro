Run START.cmd and keep its window open. Close with Ctrl+C. No system Node or project checkout is required.
The existing iCall receiver uses the Windows Npcap driver for Ethernet capture; that driver must already be installed for Npcap capture. UDP 3520 fallback is included. No driver or network settings are changed by this package.
The supplied API is the currently authorized temporary Quick Tunnel. It is not a permanent endpoint and must remain running at home.
The existing parser preserves its normalized phone and stable event ID. Original packet bytes are retained in icall-raw.log. Known incoming I/E device records close the matching active call immediately. Unstructured records use 8 seconds without matching packets as a fallback; actual ring cadence and end records must be confirmed from the office capture.
Keep data when restarting or moving this package to preserve deduplication and pending events. Do not run two receivers or two copies of this package together.
Credentials are sensitive; do not publish or share the archive publicly.

The existing WhatsApp LAN gateway is launched on its existing port 9006. Its log reports the endpoint or the precise startup error; Android must retain the matching local call-token. No phone settings are changed automatically.
